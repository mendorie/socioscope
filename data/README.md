# data/

| ディレクトリ | git | 内容 |
|---|---|---|
| `raw/` | **管理しない**（manifest のみ） | 取得したままの生データ。`manifest.jsonl` に URL・sha256・取得日時・ライセンスを記録。`socioscope run <theme> fetch` で再取得。 |
| `staged/<domain>/` | 管理する | 正規化済み Parquet。共通キー: `iso3`, `year`。1 ソース 1 ファイルを基本に。 |
| `marts/` | 管理する | テーマ別の分析用テーブル（`<theme>_<name>.parquet`）。 |
| `llm_cache/` | 管理する | LLM 構造化の結果（JSONL, ADR 0003）。 |
| `socioscope.duckdb` | 管理しない | `socioscope db build` で `staged.*`/`marts.*` view を再生成。 |

詳細: `docs/adrs/0002-parquet-as-source-of-truth-duckdb-as-derived.md`

## データのライセンス
Parquet はコード（MIT）とは別に、出典のライセンスを継承する。WID.world 由来のテーブル（`staged/wid/*`、`marts/wealth_population_panel`）は CC BY-NC-SA 4.0 なので**非商用に限る**。e-Stat 由来のテーブル（`staged/estat/*`、`marts/jp_income_class_fertility`）は政府標準利用規約（第2.0版、CC BY 4.0 互換）で、再配布時は「出典：政府統計の総合窓口(e-Stat)、国民生活基礎調査（厚生労働省）を加工」の表記が必要。OECD 由来のテーブル（`staged/oecd/*`）は OECD Terms & Conditions（2024-07-01 改定。出典表示で商用含め自由利用、OECD 発行物は CC BY 4.0）で、再配布時は「OECD (2026), OECD Tax Database / SOCX / Revenue Statistics, https://sdmx.oecd.org (accessed on 2026-10-04)」の表記と、同じ表記義務の継承が必要。WID と OECD を結合した `marts/wealth_institutions_panel` は厳しい方（WID の CC BY-NC-SA 4.0、**非商用**）に従う。出典表記は `design/data-sources.md` の記載に従う。 IPU Parline 由来のテーブル（`staged/ipu/*`、`marts/ipu_parliaments`）は **CC BY-NC-SA 4.0** で非商用に限り、再配布時は「Inter-Parliamentary Union, Parline: global data on national parliaments, https://data.ipu.org (accessed 2026-10-27)」の表記と同ライセンスの継承が必要。 総務省 結果調（`staged/soumu/*`、`marts/jp_hr_*`）と e-Stat 国勢調査（`staged/estat/census2020_prefecture`、`marts/jp_census2020_prefecture`）は政府標準利用規約（第 2.0 版）で、出典表記が必要。 財務省 予算書（`marts/jp_budget_by_organ`）・内閣法制局（`marts/jp_bill_counts`）・e-Stat 人口推計（`marts/jp_population_longterm`）も政府標準利用規約（第 2.0 版）。 World Bank WDI 由来（`staged/worldbank/*`、`marts/wdi_gdp_lcu`、`marts/wdi_population`）は CC BY 4.0 で、出典表記「World Bank, World Development Indicators (accessed 2026-10-28)」が必要。 ParlGov 由来（`staged/parlgov/*`、`marts/parlgov_elections`）は CC0 1.0（Harvard Dataverse）で、出典表記「Döring & Manow 2024, ParlGov」を付ける。 UK Parliament Bills API 由来（`staged/ukbills/*`、`marts/uk_acts`）は Open Parliament Licence v3.0 で「Contains Parliamentary information licensed under the Open Parliament Licence v3.0」の表記が必要。 Assemblée nationale open data 由来（`staged/fran/*`、`marts/fr_laws`）は Licence Ouverte 2.0 で出典表記が必要。 ILOSTAT 由来（`staged/ilostat/*`、`marts/ilo_emp_*`）は CC BY 4.0 で「ILOSTAT (accessed 2026-10-28)」の表記が必要。 IPSS 由来（`staged/ipss/*`、`marts/jp_prefecture_projection`）は出典表記「国立社会保障・人口問題研究所『日本の地域別将来推計人口（令和 5 年推計）』」が必要。 イタリア下院 open data 由来（`staged/camera/*`、`marts/it_*`）は CC BY 4.0 で「Camera dei deputati, dati.camera.it」の表記が必要。 国会会議録検索システム由来（`staged/kokkai/*`、`marts/jp_hr_sitting_days`）は出典表記「国立国会図書館 国会会議録検索システム」が必要。 OECD Government at a Glance・Trust Survey 由来（`staged/oecd/gov_finance`・`gov_trust`、`marts/oecd_gov_finance`・`oecd_gov_trust`）は OECD Terms & Conditions で「OECD (2025), Government at a Glance 2025, https://sdmx.oecd.org (accessed 2026-10-29)」の表記が必要。 Eurobarometer 由来（`staged/eurobarometer/*`、`marts/eb_trust_parliament`）は欧州委員会の再利用方針（Decision 2011/833/EU）で「European Commission, Standard Eurobarometer 91–103, Volume A, via data.europa.eu」の表記が必要。
