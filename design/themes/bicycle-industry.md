# テーマ: 日本および世界の自転車産業はどのような状況なのか（セグメント分化と、自動車・二輪との対比）

作成 2026-10-22。データソース調査（`design/data-sources.md` 自転車節）を終え、**データを見る前**に問い・仮説・指標・判定基準を固定する。

## 動機（伝えられている像）
- スポーツ車（ロードバイク等）はエントリー〜ミドルグレードの売れ行きが鈍く、セールが常態化していると言われる。
- シマノの自転車部品セグメント売上は 2022 年のピークから落ち、2023 年に大きく減った（2025 年は小幅増）。
- 一方、日常の足としての自転車（電動アシスト車・軽快車）は堅調に見える。
- Blue Lug のような趣味・ファッションに振り切った小規模ショップはニッチで成り立っているように見える。

これらは別々の出来事なのか、ひとつの構造（**日用品化した下層と趣味化した上層への二極化、その間の薄い中間層**）の現れなのか。自動車（軽 ↔ 登録車・輸入車）、二輪（原付 ↔ 大型）にも同じ構造が見られるのかを比べる。

## 問い
1. **量と価格**: 日本・欧州・米国で自転車の販売台数・金額・価格はコロナ前後でどう動いたか。台数減は全体か、特定セグメント（スポーツ車）か。
2. **セグメント分化**: 電動アシスト車・軽快車（実用）と、スポーツ車（趣味）で、台数・単価・在庫の動きは分かれているか。
3. **部品供給側**: シマノ等の部品売上の落ち込みは、完成車需要の落ち込みより大きいか（在庫調整の増幅）。回復は需要の回復か在庫消化か。
4. **ニッチ**: 自転車小売の事業所数・販売額・個人経営比率は、量販・チェーンへの集約と小規模専門店の残存のどちらを示すか（Blue Lug 的な店の直接データはない。代理指標で見る）。
5. **対比**: 同じ「二極化・中間層の薄さ」が自動車・二輪にもあるか。コロナ後の在庫サイクルは三産業で位相がどう違うか。

## 仮説（事前登録、2026-10-22）
- **H1（コロナ特需と反動）**: 2020–21 年に台数・輸入が急増し、2022–24 年に反動で減った。2024–25 年の水準はコロナ前（2017–19 平均）を**下回らない**（日本・EU の完成車台数）。「業界不況」の多くは特需からの正常化で説明できる。
  - 判定: 2024–25 平均 / 2017–19 平均 ≥ 0.95 なら整合、< 0.85 なら不支持。
  - **結果（R1、2026-10-22、`themes/bicycle-industry/reports/2026-10-22-r1-volume-price.md`）: 不支持。** 日本 国内販売 0.83、日本 輸入 0.69、米 0.73、独 0.57、英 0.47、蘭 0.63。台数はコロナ前を割り込んでいる。
- **H2（セグメントの分離）**: 日本国内では、電動アシスト車の台数はコロナ後も減らず単価は上がる一方、スポーツ車は台数・単価ともに下がる。すなわち価格×台数の動きが**逆向き**。
  - 判定: JBPI 国内向統計・POS で 2022→2025 の台数変化率が 電動アシスト ≥ 0 かつ スポーツ < −10% なら整合。
- **H3（部品の増幅＝ブルウィップ）**: シマノ自転車部品売上の 2022→2023 の落ち幅（%）は、同期間の世界完成車需要の代理（主要国輸入台数・EU 販売台数）の落ち幅の **1.5 倍以上**。回復局面でも部品の方が遅れる。
  - 判定: 比 ≥ 1.5 で整合。ついで 2024–25 に完成車が横ばい・部品が増収なら「在庫消化の終了」と記述。
  - **結果（R2、2026-10-22、`themes/bicycle-industry/reports/2026-10-22-r2-bullwhip-price.md`）: 不支持。** シマノ 自転車部品 −29.5% ÷ 6 か国（日米独蘭英伊）輸入台数 −25.6% = 1.15。EU 販売台数は未取得。2022→2024 では 1.56（探索的）。
- **H4（価格の二極化）**: CPI の自転車 A（低価格）と自転車 B（高価格）、家計調査の平均購入価格、HICP 自転車の動きから、2022 年以降「低価格帯は上昇（コスト転嫁）、高価格帯は横ばい〜下落（セール）」が観測される。
  - 判定: 2022→2025 で 自転車 A 指数の上昇率 − 自転車 B 指数の上昇率 ≥ 5pt なら整合。
  - **結果（R2、2026-10-22）: 不支持。** 自転車Ａ +13.0%、Ｂ +15.1%、差 −2.1pt。高価格帯の方が上がった（2015→2022 は Ａ +24.3%、Ｂ +8.2% と逆）。
- **H5（小売構造）**: 自転車小売業の事業所数は減少し続けるが、販売額の減少はそれより小さい（1 店当たりの大型化）。ただし個人経営の事業所数の減少率は法人より大きい（小規模専門店の淘汰）。ニッチの「成功」は数の上では観察できず、生き残り率としてしか見えないと予想。
  - 判定: 経済センサス 2016→2021 の 事業所数変化率 < 販売額変化率 で (a) 整合。個人経営の減少率 > 法人 で (b) 整合。
  - **結果（R3、2026-10-22、`themes/bicycle-industry/reports/2026-10-22-r3-retail.md`）: (a) 整合（定義差を含む: 2021 の販売額は法人のみ。法人同士は判定不能）、(b) 整合（個人 −19.0%、法人 −3.2%）。** ただし個人店の減少は小売業計（−22.6%）にも共通し、自転車小売業に固有ではない。
- **H6（対比: 構造は共通か）**: 自動車では軽の比率が高止まりし輸入車は高価格帯に偏る、二輪では原付が長期減少し 軽二輪・小型二輪（趣味）は維持〜増、という「実用と趣味の分化」が自転車と同形で見られる。ただしコロナ後の反動の深さは自転車が最も大きい（在庫が軽く輸入依存のため）。
  - 判定: 2022→2025 の台数変化率を 実用層（軽／原付／電動アシスト）と 趣味層（輸入車 500 万円超／小型二輪／スポーツ車）で並べ、三産業とも 実用層 ≥ 趣味層 なら「同形」と判定。自転車の 2021→2024 の下落率が三産業で最大なら後段も整合。

- **H7（2026-10-22 追加、R1〜R3 の結果を見た後に立てた仮説。判定手順は追加計算の前に固定）: コロナ後の台数減少は「特需の先食い」で説明できる。** すなわち 2015–19 年の線形トレンドを 2020 年以降に延ばしたとき、2020–21 年の累積超過 E と 2022–24 年の累積不足 F（絶対値）は同程度で、相殺する。
  - 対象系列: 日本 国内販売（生産動態統計 完成車 3 区分）、完成車輸入台数（日・米・独・英・蘭、HS 8712）、シマノ 自転車部品売上。補助: 電動アシスト・軽快車・その他、6 か国合計。
  - 手順: 2015–2019 の 5 点に最小二乗の線形トレンドを当て 2020–2024 に外挿。E = Σ_{2020–21}(実績 − トレンド)、F = Σ_{2022–24}(実績 − トレンド)。比 R = −F / E。
  - 判定: E > 0 かつ 0.8 ≤ R ≤ 1.5 → 「先食いで説明できる（整合）」。R > 2 → 「先食いでは説明できない（構造的縮小を含む、不支持）」。1.5 < R ≤ 2 → 中間。E ≤ 0（特需なし）→ 判定不能（反動の前提がない）。
  - 頑健性: トレンド期間 2012–19・2017–19、対数線形、2025 を含む（日本の国内販売・シマノ）。
  - **結果（R4、2026-10-22、`themes/bicycle-industry/reports/2026-10-22-r4-pullforward-origin.md`）: 6 か国合計は整合（R = 0.87、頑健 0.52〜0.98）だが水準 L = 0.79（新しい常態）。国別 R はトレンド期間で入れ替わり判定しない。日本国内販売は 3 点トレンドのため R は判定に使わず、3 局面の水準（99 / 83、電動 113・軽快車 63・その他 59）のみ。シマノは不足なし（L 1.36）。2025 年の輸入で先食いの穴が埋まるかを追跡。**
  - **局面の扱い（2026-10-22 追記、計算前）**: コロナ前（〜2019）・特需（2020–2022）・特需後（2023〜）の 3 局面を分けて報告する。先食いの検定（E と F）に加え、特需後の水準 L = 特需後（2023–24、あれば 2025）の実績平均 ÷ 同期間のトレンド値平均 を出す。L ≥ 0.9 → 「特需後はコロナ前トレンドに戻っている」、L < 0.8 → 「特需後の水準はコロナ前トレンドを下回る（新しい常態）」、間は中間。R（先食い）と L（水準）は別の問いで、R が整合でも L が低ければ「先食いの穴」が続いている段階と解釈し、R が不支持で L が低ければ構造的縮小とする。特需の年は 2020–2022 とし（シマノと部品は 2022 がピーク）、F は 2023–24 で再計算した版も並べる（主は事前登録どおり 2022–24）。
- **H8（2026-10-22 追加、同上）: エントリー〜ミドル層の苦戦は、部品供給の中国シフトと、台湾産（高級車）の値下がりとして貿易統計に現れる。**
  - データ: Comtrade 輸入の相手国別（中国 156・台湾 490・世界計 0。その他 = 世界 − 中国 − 台湾）、報告国 日・米・独・蘭・英、HS 8712（台数・金額）と 8714（金額）、2015–2024。到達性確認のため 2023 年の 1 回分だけ目視した（台湾産完成車の単価が中国産より高いことは確認済み。それ以外の判定基準はデータを見る前に固定）。
  - (a) 台湾産完成車の輸入単価（USD/台）は 2022→2024 に下落する（セールの代理）。判定: 5 か国の台湾産単価の中央値変化率 ≤ −10% で整合、≥ 0 で不支持。
  - (b) 部品（8714）輸入に占める中国のシェア（金額）は 2019→2024 に上昇する。判定: 5 か国の中央値で +5pt 以上で整合、≤ 0 で不支持。
  - (c) 記述: 完成車の台湾産シェア（台数・金額）の推移、台湾産／中国産の単価比。
  - **局面の扱い（同上）**: (a)(b) の主判定に加え、コロナ前（2015–19 平均）と特需後（2023–24 平均）の比較を並べる（台湾産単価の 特需後／コロナ前、中国部品シェアの 特需後 − コロナ前）。スポーツ車の需要は特需で一度膨らみ 2023 年以降は別の状態にある可能性があるため、2022 年起点の変化だけで判断しない。
  - 言えないこと: 原産国は価格帯の代理にすぎない（台湾産にも低価格帯、中国産にも高価格帯がある）。単価は為替と品目構成を含む。
  - **結果（R4、2026-10-22）: (a) 不支持（台湾産単価は 5 か国すべてで上昇、中央値 +48.5%、特需後／コロナ前 2.35 倍。台数シェアは半減し「少数・高額」へ）。(b) 中間（中央値 +4.99pt、閾値直下。英 +11.97、独 +7.82 で上昇、米 +4.99、日 −1.62、蘭 +0.67）。**

言えないこと（事前に明記）: 本テーマは**記述と比較**であり因果の識別はしない。「セールが増えた」ことの直接データ（値引き率）は存在せず、価格指数と平均購入価格の代理で見る。スポーツ車の台数は政府統計では分離できず、JBPI の推計（POS は家電量販を含まない、カバー率 4〜5 割）に依存する。シマノの売上は世界合計で、日本の需要とは一致しない。

## 指標
- 台数・金額: 国内生産（完成車・電動アシスト・部品）、輸入・輸出（HS 8712 / 8714 / 8711.60）、JBPI 国内向流通台数（車種別）、POS 販売台数・金額（車種別）、EU・米・独の販売台数と e-bike 比率
- 価格: CPI 自転車 A/B（日本）、HICP CP0713（EU 各国）、BLS SERC01（米、自転車を含むスポーツ用車両）、家計調査 平均購入価格、独 ZIV 平均価格
- 供給側: シマノ 自転車部品セグメント売上・営業利益（四半期・地域別）、Giant・Merida 月次売上、Fox Factory 自転車セグメント
- 小売: 経済センサス 自転車小売業 事業所数・従業者数・年間商品販売額（経営組織別）、あさひ 月次既存店売上
- 対比: 乗用車（普通・小型・軽）・二輪（原付一・二種、軽二輪、小型二輪）の生産・出荷・新車販売、輸入車 価格帯別登録台数、CPI 軽乗用車・普通乗用車 A/B、HICP CP0711/CP0712、家計調査 自動車・自動二輪車 購入

## 分析の段階
1. 記述: 日本・EU・米・独の完成車台数（2010–2025）と e-bike／電動アシスト比率。コロナ前平均＝100 の指数で三地域を重ねる（H1）。
2. セグメント: JBPI 車種別台数・金額・単価（2018–2025 月次）。電動アシスト vs スポーツの価格×台数の軌跡（H2）。
3. 供給連鎖: シマノ四半期売上（地域別）と 日本・EU・米の輸入台数・HICP を同一時間軸に置き、ピークからの落ち幅と回復時期のずれを測る（H3）。
4. 価格: CPI 自転車 A/B、HICP 各国、家計調査 平均購入価格の 2015–2025（H4）。
5. 小売構造: 経済センサス 2016 → 2021（可能なら 2012・2014 商業統計）、経営組織別（H5）。
6. 対比: 三産業の 実用層 / 趣味層 の台数指数（2015=100）と、在庫（生産動態統計）・輸入のコロナ後サイクル（H6）。
7. 報告: `docs/methodology/report-template.md` に従い、事前判定基準と結果を表で並べる。因果は主張しない。

## 既知の落とし穴
- **スポーツ車の定義**がソースごとに違う（JBPI: 車種分類、POS: 小売側分類、GfK: 販路限定）。混ぜない。定義を report に書く。
- **電動アシスト車の輸入**は HS 8711.60 に原付・電動バイクと混在する。国内生産（生産動態統計）の電動アシスト行を主にする。
- **シマノ売上は世界合計・円建て**。為替の影響を除くため現地通貨ベースの開示があればそれを使い、無ければ注記する。
- 生産動態統計・貿易統計は 1 ファイル＝全品目で大きい。manifest を残し、自転車行だけを stage する。様式変更（2023-01 月次）に注意。
- JBPI・シマノ・METI・あさひはサイトがボット UA を拒否する／メンテで落ちる。fetcher に UA とリトライを持たせ、fail-closed にする。
- 協会統計（JAMA・自販連・全軽自協・JAIA・JBPI）は利用規約が無い。出典明記で引用し、raw は非コミット、staged も再配布しない前提で扱う（`design/data-sources.md`）。
- Eurostat HICP は `prc_hicp_midx` が廃止予定。`prc_hicp_minr` の次元を構造 API で確認してから実装する。
- 価格指数はヘドニック調整済みで「セール」を直接は捉えない。平均購入価格（家計調査・ZIV）と併置する。
- Blue Lug 等は非上場で財務データがない。「ニッチの成功」を直接検証することはできないと明記し、代理指標（小売構造）に限る。
