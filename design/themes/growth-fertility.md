# テーマ: 経済成長と出生率の関係（国間・国内のフラクタル構造）

## 問い
1. **国間**: 経済成長率（および所得水準）と出生率（TFR）の関係はどのような形か。時代で変わったか。
2. **国内**: 同じ国（まず日本）で、所得・資産階層と出生率の関係は国間の関係と**同じ形（フラクタル）**か、逆向きか。

## 仮説（事前登録）
- H1: 国間では所得水準と TFR は負の相関（人口転換）。ただし高所得国内では近年 J 字反転の兆候がある。
- H2: 成長「率」と TFR の関係は水準より弱く、ショック（景気後退）への短期反応として現れる。
- H3: 日本国内では所得階層と有配偶率・出生数の関係は正（国間と逆）で、フラクタルではない。
- H6（2026-10-06 追加、H5 の結果を見た後に立てた仮説。データ調査の後・データを見る前に手順を固定）: 北欧の 2010 年以降の低下は、所得・景気・政策では説明できず（H5）、文献は「理想子ども数の低下」「将来への不確実性」を残差の説明に挙げる。意識調査の国別集計で、(a) 2011 年時点の理想子ども数は国間の TFR 水準と正の関連を持つが、北欧は 2011 年に理想が高かったので、2011 年の理想では**その後の北欧の低下を予測できない**、(b) 2011 → 2020 年代に理想子ども数が下がった幅は北欧で大きい（選好変化仮説と整合的）、(c) 生活・経済への期待（不確実性の代理）の低い国ほど 2019 年以降の TFR 低下が大きい、を確かめる。
- H7（2026-10-13 追加、H4 の結果を見た後に立てた仮説。検証手順・判定基準は追加データ（WDI 固定 US$ GDP・女子初等就学率・乳児死亡率）を見る前に下記に固定）: 国間の「豊かな国ほど TFR が低い」右下がりは、豊かさそのものの差（A）ではなく、**人口転換の進み具合の差**によって生じており、豊かさは転換と並走しているだけ（B）である。対立仮説 C「豊かさが転換を引き起こし、転換が TFR を下げる（豊かさは上流）」と B を分けるため、(T3) 転換開始時の所得は国間で大きくばらつき（閾値がない）、(T4) 同じ国の中で所得の伸びは死亡率低下・教育拡大・TFR 低下に先行しない、を確かめる。
- H5（2026-10-06 追加、文献調査とデータ調査の後・データを見る前に固定）: (a) 家族関連の公的支出は同じ国の中で TFR と正の関連を持つが、その大きさは 2010 年以降の北欧の低下幅を説明できるほど大きくない。(b) 国内の階層勾配は欧州（学歴）でも男性で正であり、女性では北欧で正・南欧／東欧で弱いか負。韓国の新婚夫婦では夫婦所得と有子率は負（共稼ぎ交絡）。(c) 北欧の 2010 年以降の TFR 低下は第 1 子（無子化）が主で、全学歴層で起きている。
- H8（2026-10-17 追加、H7 の結果を見た後に立てた仮説。part2 記事の「先行指標の背景にある仕組み」節の 4 仮説 M1〜M4 に、対抗仮説 M5（家族計画の普及）を加え、検定手順・判定基準・最終仮説の文型を追加データ（DHS 多指標・WDI 初婚年齢等）を見る前に下記に固定。シリーズ最終回）: 死亡率低下と女子教育が出生率を下げる仕組みは、6→3 人の段階では「保険としての多産の解消（M1）」と「学歴による望む数の低下（M3）」、3→2 人未満の段階では「結婚の遅れ・減少（M2）」が主役であり、望まない出生の減少（M5）は従である。
- H4（2026-10-05 追加、H1〜H3b の結果を見た**後**に立てた仮説。検証手順は結果を見る前に下記に固定）: 国間の「所得水準 × TFR」の負の勾配は、所得そのものではなく**人口転換の段階**（死亡率・教育・都市化・女性就業）が TFR を決め、所得が段階と相関することで現れる見かけの関係である。したがって (a) 段階指標を揃えると国間の所得勾配は大きく減衰し、(b) 段階を固定した上では所得と TFR の関係は 0 以上（所得効果）で、(c) 国内の所得（資産）階層勾配は国の段階が進むほど負から 0・正へ向かう（勾配自体が段階に依存し、フラクタルではない）。

## 指標
- TFR、合計出生数、年齢別出生率、有配偶率
- 一人当たり GDP（PPP）、GDP 成長率、失業率、女性労働参加率
- 日本国内: 所得階層別の有配偶率・子ども数（国民生活基礎調査・出生動向基本調査の公表集計表）

### H2（成長率・景気後退ショック）の事前登録の詳細 — **実装済み**（2026-10-04、結果を見る前にスクリプト docstring に固定）
データは WDI の `gdp_growth`（`NY.GDP.MKTP.KD.ZG`、1961 年以降）と `tfr`。ラグ・差分は前年の行が存在するときだけ作る（補完しない）。識別戦略は**なし**（景気後退は外生ではない。予期・測定・逆の因果）。結果は関連・「整合的」までで因果効果とは書かない。
- (a) 水準 vs 成長率: 同一サンプル（ln GDP pc と成長率ラグ 0–3 が揃う 1990–2024）で二元 FE（国＋年、国クラスタ SE）の `tfr ~ ln_gdp` と `tfr ~ growth_{t-k}`（k=0..3 単独・合算）を、FWL で残差化した標準化係数と within-R² で比較する。成長率の方が小さければ「水準より弱い」と整合的。
- (b) 分布ラグ: `ΔTFR_t ~ growth_t..growth_{t-3}` ＋国 FE（国クラスタ SE）。累積反応 Σ b_k を分散共分散から区間推定し図示。年 FE 入りも併記。
- (c) イベントスタディ: 景気後退 = 成長率 < −2 %（主。< 0 %, < −5 % は頑健性）、同一国で前イベントから 5 年以上空ける（昇順の貪欲法）。event time は最も近いイベントとの差、−3..+5 に端点ビン化、参照 k=−1。`ΔTFR`（主）と `Δ ln TFR`、国＋年 FE、国クラスタ SE。k=−3,−2 は pre-trend 確認。
- (d) 異質性（事前リスト）: WB 高所得 vs 非高所得（時間不変分類）、観測年 2000 年未満 vs 以降、産油国除外、人口 100 万人未満の行除外（H1 の `OIL_STATES`/`SMALL_POP` を import）。
- 頑健性（事前リスト）: 閾値、2020–21 年除外、Δ ln TFR、人口加重 WLS、1990 年以降サンプル。2008–09・2020 は年 FE に吸収されるので、国間平均 ΔTFR の推移を**記述図**として別掲。
- 事後に追加（探索的、report で明記）: 端点ビン化しない窓（−3..+5 の外を 0）版のイベントスタディと、event time 別の国内デミーン済み平均 ΔTFR の記述表。

### H4（段階 vs 所得: 国間の負の勾配は見かけか）— 事前登録（2026-10-05）
**実装済み**（2026-10-05、`reports/2026-10-05-h4-stage-vs-gdp.md`）。判定結果: (a) 整合的、(b) 主仕様で整合的、(c) 事前基準では不支持（転換完了層のみ勾配ゼロ）、(d) 部分的。
**動機**: H1 で国間 −1.04・国内（within）≈ 0、H3/H3b で日本国内は正。「所得 → 出生率」が一枚の因果なら国間でも国内でも同符号になるはずで、符号が逆転するのは、国間では所得と相関する別の構造（人口転換の段階）が TFR を決めているからではないか、というユーザー提案の仮説。経済学的には Becker の数量–質トレードオフ・時間の機会費用（所得効果 vs 代替効果）、Galor–Weil の統一成長理論、Doepke–Hannusch–Kindermann–Tertilt (2023) が整理した「高所得国で所得–出生率の関係が負から正に転じた」観察に対応する。**注意**: この仮説は H1〜H3b の結果を見た後に立てたものである。以下の推定量・サンプル・判定基準は、追加データ（下記）を見る**前**に固定した（DHS API は到達性確認のため Afghanistan 2015・Albania 2008 の 10 行だけ目視した）。

**追加データ**
- WDI 段階指標（`worldbank.INDICATORS` に追加、mart `growth_fertility_panel` の列）: `u5_mortality` = `SH.DYN.MORT`（5 歳未満死亡率、出生千対。人口転換の標準的マーカー）、`fem_sec_enrol` = `SE.SEC.ENRR.FE`（女子中等教育総就学率 %）、`urban_share` = `SP.URB.TOTL.IN.ZS`（都市人口 %）、`fem_lfp` = `SL.TLF.CACT.FE.ZS`（女性労働参加率 %、ILO 推計、1990 年以降）、`life_exp` = `SP.DYN.LE00.IN`（出生時平均余命）。
- DHS Program Indicator Data API（`api.dhsprogram.com`、キー不要、引用必須。`design/data-sources.md`）: 指標 `FE_FRTR_W_TFR`（調査前 3 年の TFR、15–49 歳）× 特性 `Wealth quintile`（Lowest/Second/Middle/Fourth/Highest。**資産ベースの国内相対順位**であり所得額ではない）。全調査（DHS・MIS・AIS、取得後の実数: 1990–2025、77 か国・313 調査。countries エンドポイントは 92 件だがデータがあるのは 77 か国）。mart `marts/dhs_tfr_by_wealth_quintile`（long: iso3, country, survey_id, survey_year, survey_type, quintile 1..5, quintile_label, value, ci_low, ci_high, denominator_weighted, source）。ISO3 は `/rest/dhs/countries` の `ISO3_CountryCode` で付ける（無ければ行を落とし skipped に残す）。

**推定量（スクリプト `analysis/a20261005_h4_stage_vs_gdp.py` に固定）**
- (a) **減衰**: H1 と同じフレーム（1990–2024、tfr・gdp 観測）を 5 指標 listwise で絞った**同一サンプル**で、国間（pooled OLS ＋ 年 FE、国クラスタ SE）の `tfr ~ ln_gdp` と `tfr ~ ln_gdp + u5_mortality + fem_sec_enrol + urban_share + fem_lfp + life_exp` を比較する。主判定は `ln_gdp` 係数の比（調整後/調整前）。段階指標は 1 本ずつ加えた版も出す（どの指標が減衰を担うか）。**判定**: 比 ≤ 0.5 で「H4(a) と整合的」、0.5–0.8 で「部分的」、> 0.8 で「不支持」。ただし段階指標は所得の**媒介**でもありうるため、減衰は「所得の国間関連は段階を経由または段階に交絡している」までしか言えず、「所得は無関係」とは言わない。
- (b) **段階固定の所得係数**: 同一サンプルで二元 FE（国＋年）`tfr ~ ln_gdp + 段階指標`。**判定**: `ln_gdp` の 95% CI 下限 ≥ 0 なら「H4(b) と整合的（所得効果 ≥ 0）」、CI が 0 を含めば「判定不能」、上限 < 0 なら「不支持」。段階指標の within 係数も報告する（これは H4 の主張の一部ではなく記述）。
- (c) **段階層別の国間勾配（Simpson 型分解）**: 5 歳未満死亡率で層を事前固定（< 10, 10–25, 25–50, 50–100, ≥ 100 /千）。層内の pooled＋年 FE 勾配 `tfr ~ ln_gdp` を層ごとに推定し、全体の勾配と並べる。**TFR で層別しない**（結果変数での層別は同語反復）。**判定**: 全層で層内勾配が全体勾配の半分以下（絶対値）なら整合的。層内勾配が全体と同程度に負なら不支持。
- (d) **国内勾配の段階依存（フラクタル検定の本体、DHS）**: 調査ごとに 5 五分位が揃う行から `gap = TFR_Q5 − TFR_Q1`（主）、`slope` = 五分位順位 1..5 への OLS 傾き、`ratio = Q5/Q1`（補助）を作る。調査年の WDI（`ln_gdp`、`u5_mortality`、`fem_sec_enrol`）を同じ iso3×year で結合（補完しない。該当年欠損は落とす）。モデル: `gap ~ ln_gdp`（pooled、国クラスタ SE）、`gap ~ ln_gdp + C(iso3)`（同一国の複数調査内）、年トレンド調整版 `+ survey_year`。段階代理を `u5_mortality`（符号は逆向きを予測）、`fem_sec_enrol` に替えた版。**予測**: `∂gap/∂ln_gdp > 0`（豊かな段階ほど負の勾配が浅い）。**判定**: pooled と国 FE の両方で CI 下限 > 0 なら「整合的」、片方なら「部分的」、どちらも 0 を含むか負なら「不支持」。記述: gap < 0 の調査の割合、gap ≥ 0 の調査の一覧。
- (e) **日本との接続（記述のみ）**: H3/H3b の日本の勾配（男性有配偶率 +0.17〜0.20、児童世帯割合 +0.12）は指標が違うため (d) の回帰には入れない。(d) の図に「DHS 調査国の段階の範囲」を示し、日本（ln GDP ≈ 10.6、U5MR ≈ 2）が範囲外の延長上にあることを図示する。「延長したら正になる」とは**言わない**（外挿）。

**サンプル・頑健性（事前リスト）**: (a)(b)(c) は H1 の `OIL_STATES` 除外・人口 100 万未満除外・2020–24 除外・`fem_sec_enrol` を外した 4 指標版（就学率は欠損が多い）。(d) は SurveyType = DHS のみ／全タイプ、`slope`・`ratio`、1 国 1 調査（最新）に絞った版、人口加重なし（主）／加重。

**言えないこと（事前に明記）**: 識別戦略なし。段階指標は所得の媒介か交絡かを区別できない（Baron–Kenny 型の「媒介分析」はしない）。DHS の富裕五分位は国内の相対資産順位で、日本の個人所得階級とは定義が異なる。TFR は女性ベース、日本側は男性有配偶率。DHS 対象国は低・中所得国に偏り、高所得国の国内勾配は本データでは観測できない。

### H5（韓国・欧州の国内階層勾配と「手厚い政策でも回復しない北欧」）— 事前登録（2026-10-06）
**実装済み**（2026-10-06、`reports/2026-10-06-h5-europe-korea-policy.md`）。判定結果: (a) 整合的（支出変化で説明できる北欧の低下は 0–12%。北欧の支出変化が ≈0 のため政策効果の検定ではない）、(b) 男性 正 23/31・負 0 で事前基準 25 に届かず不支持、女性は北欧 5 正・南欧 4 負、韓国は新婚夫婦内で負（記述）、(c1) 不支持（第 1 子寄与率 0.33–0.45。DNK は 2010 欠損で評価不能だが他 4 か国が < 0.5）、(c2) LFS 分母の 2021 年断絶で判定不能。事後追加: (c1) の 2012 起点（探索的）。

### H6（意識調査: 理想子ども数と将来期待は北欧の低下を説明するか）— 事前登録（2026-10-06）
**実装済み**（2026-10-06、`reports/2026-10-06-h6-fertility-ideals.md`）。判定結果: (a) 整合的（r = +0.56、北欧 3 か国の 2011 年の理想は EU-27 中央値より高い。**事前登録の誤り**: NO は EU 外で EB 75.4 に含まれないため北欧は DK FI SE の 3 か国）、(b) 事前基準では判定不能（重なりは 8 か国で NO・HR は EB に無い。FI・DK の Δideal は 8 か国中 1・2 位の低下）、(c) 不支持（生活全般の期待と ΔTFR の ρ ≈ 0。国の経済への期待は COVID 期除外で ρ = 0.33）。
**問い（ユーザー）**: Eurobarometer・GGS の国別集計を取り込み、北欧の低下の残差（H5）が「理想子ども数の低下」「将来への不確実性」で説明できるかを見る。

- 頑健性（事前リスト）: (a) 一般理想・全年齢、Spearman、(b) EB 全年齢 vs GGS Total、(c) 項目の入れ替え、2020–21 除外。

**言えないこと（事前）**: 国レベルの相関のみ（n は 10〜27）。質問文・母集団が時点で異なる。理想子ども数は規範的回答で、意向・行動と一致しない（文献: ideal–actual gap）。不確実性の代理は「期待」であり不確実性の分散ではない。識別戦略なし。


### H7（なぜ国間では豊かな国ほど TFR が低いのか: 段階の差か、豊かさか）— 事前登録（2026-10-13）
**動機**: H4 は「段階指標をそろえると国間の所得勾配が −0.94 → −0.18 に縮む」ところで止まり、段階が所得の結果（媒介）か、所得と並走する別の構造（交絡）かを分ける検定を持たなかった。本仮説はその区別を主役にし、「国の間」だけに絞る（途上国の中・日本の中は扱わない）。詳細な設計と記事構成: `docs/specs/growth-fertility-h7-between-gradient.md`。**注意**: H4 の結果を見た後に立てた仮説である。以下の推定量・サンプル・判定基準は追加データを見る前に固定した。

**答えの候補（3 択。結果はこのどれか、または量つきの混合として断定形で書く）**
- A: 豊かさの差そのものが TFR の差を作っている（段階をそろえても、転換後の国の間でも、所得勾配が残る）。
- B: 人口転換の進み具合の差が TFR の差を作っており、豊かさは並走しているだけ（転換後の国間で所得勾配 ≈ 0。転換は所得の閾値で始まらない。同じ国の中で死亡率低下・教育拡大が TFR 低下を伴い、所得の伸びは先行しない）。
- C: 豊かさが転換を引き起こし、転換が TFR を下げる（段階をそろえると所得勾配は消えるが、転換開始時の所得は狭い帯に集中し、同じ国の中で所得の伸びが先行する）。

**追加データ**（WDI、`worldbank.INDICATORS` に追加。adapter 追加なし）: `gdp_pcap_const` = `NY.GDP.PCAP.KD`（一人当たり GDP、2015 年固定 US$、1960–。時間方向と転換開始時所得に使う。国間の水準比較は従来どおり PPP）、`fem_prim_enrol` = `SE.PRM.ENRR.FE`（女子初等就学率、1990 年以前の教育段階の代理）、`infant_mortality` = `SP.DYN.IMRT.IN`（乳児死亡率、死亡率の頑健性）。Maddison Project は採用しない（TFR 側に 1960 年以前の実測系列が無いため）。

**転換開始年の定義**（事前固定）: 1960–1975 の TFR 最大値が 4.5 以上の国を対象とし、最大値から 10% 下回りその後二度と戻らない最初の年を開始年とする。既存 mart の試算で 216 か国中 157 が対象、155 で開始年が特定（中央値 1975、うち 124 は 1990 年以前）。最大値 < 4.5 の国は「1960 年に転換済み」の層として扱い、開始時所得の分析には入れない。頑健性: 閾値 4.0 / 5.0、低下率 15%、5 年移動平均で判定。

**検定（T1〜T6）と判定基準**（SE は国クラスタ。全検定を 1 スクリプトで決定的に実行し、判定を標準出力に出す）
- **T1 Gelbach 分解**: H4 と同一サンプル（1990–2024、段階指標 5 本 listwise）で、`tfr ~ ln_gdp + C(year)` の係数 β₀ と段階指標全部入りの β_full の差を、各指標 k の寄与 δ_k = Γ_k × β_k（Γ_k: 指標 k を ln_gdp に回帰した係数、β_k: 全部入り式の係数）に分解する。Σδ_k = β₀ − β_full、順序非依存。S = Σδ_k / β₀。**判定**: S ≥ 0.6 → B/C に 1 点、S < 0.4 → A に 1 点、間は点なし（混合と記述）。
- **T2 転換後の層の所得勾配**: 段階の複合指標 = ln(5 歳未満死亡率)・平均余命・女子中等就学率の第 1 主成分（同一サンプルで固定、転換が進むほど大きい符号）。複合指標の五分位（事前固定）ごとに `tfr ~ ln_gdp + C(year)`。**判定**: 最上位層の 95% CI が 0 を含み |点推定| ≤ 0.20 → B/C に 1 点。CI 上限 < 0 かつ点推定 ≤ −0.30 → A に 1 点。補助: 転換開始から 30 年以上の国だけの層。途中の層に残る負の勾配は「転換の速さが所得と相関する分」として大きさを報告する。
- **T3 転換開始時の所得のばらつき**: 開始年が特定できる国の開始年の一人当たり GDP（固定 US$）の p90/p10。**判定**: ≥ 5 → B に 1 点、≤ 2.5 → C に 1 点、間は点なし。補助: 開始時の 5 歳未満死亡率の p90/p10 を並べる（所得より揃っていれば B の傍証）。開始年を 1960 年時点の ln GDP と同一地域の先行転換国割合に回帰（記述）。
- **T4 同じ国の中の順序（主検定）**: (i) 開始年を 0 とするイベント時間（−20..+40）で ln GDP（固定 US$）・ln(5 歳未満死亡率)・女子就学率・TFR の国平均軌跡（0 年値からの差分）。(ii) 開始前 10 年と開始後 10 年の年平均所得成長率と同時期の世界平均との差、開始前 10 年の成長率が世界平均を上回る国の割合。(iii) 10 年長期差分 `Δ₁₀tfr ~ Δ₁₀ln_gdp + Δ₁₀ln(u5mr) + Δ₁₀fem_enrol + 国 FE + 期間 FE`（1960–2024、重ならない区間、標準化係数も報告）。(iv) 前期（1 ラグ）の Δ₁₀ln(u5mr)・Δ₁₀ln_gdp を同時に入れ、どちらが今期の ΔTFR を予測するか。**判定**（まとめて 1 点）: 「(ii) の割合 ≤ 50%」かつ「(iii) で死亡率・教育の標準化係数の絶対値が所得より大きい」→ B に 1 点。「(ii) の割合 ≥ 70%」かつ「(iv) で前期の所得変化が ΔTFR を予測し、前期の死亡率変化は予測しない」→ C に 1 点。年単位の先行・遅行は読まない（WDI TFR は推計で平滑）。
- **T5 反例の計数**: 1960（固定 US$ が無ければ最初の観測年）→ 2024 の所得倍率と TFR 低下幅で 4 象限（所得「伸びた」= 3 倍以上、TFR「下がった」= 2.0 以上の低下、事前固定）。「豊かにならずに下がった国」「豊かになったのに下がらなかった国」の一覧・件数と、各群の死亡率・教育の変化。**判定**: 両象限とも ≥ 10 か国で、かつ「豊かにならずに下がった国」の死亡率低下幅の中央値が全体の中央値以上 → B に 1 点。「豊かにならずに下がった国」< 5 → C に 1 点。
- **T6 逆向き（記述のみ、点なし）**: イベント時間で開始後 +10..+30 年の所得成長率が開始前より高いか（人口ボーナス）。

**スコアカード**: 最多得点の答えを見出しにする。同点または 1 点差のときは「主に X、ただし Y が △割」と T1 の S と T2 の残差勾配で量を書く。どの答えにも 2 点以上つかない場合のみ「3 つの説明のどれとも合わない」と書き、何が合わないかを具体的に書く。「分からない」を第 1 文に置かない。見出し文のテンプレートは spec に事前記載。

**頑健性（事前リスト、全部報告）**: 産油国除外（`OIL_STATES`）、人口 100 万未満除外、人口 10 万未満除外、2020–24 除外、開始年定義 3 通り、所得系列 PPP／固定 US$ の両方で T1/T2、複合指標を死亡率のみ／3 指標の標準化平均に替える、T4 の差分幅 5 年・20 年、T1 の 4 指標版。

**言えないこと（事前固定、記事では 3 項目以内）**: 順序は因果の証明ではない（家族計画プログラム・宗教・政策が両方を動かしうる）。開始時所得のばらつきは「閾値がない」ことを示すだけで、所得が転換の速度に効く可能性は残る（T2 の残差勾配で定量化）。1960 年に転換済みの国の転換開始は本データの外。途上国の年単位のタイミングは信用しない。識別戦略は固定効果・長期差分・イベント時間整列のみで、自然実験は無い。

### H8（死亡率低下と女子教育は「どの仕組みで」出生率を下げるのか）— 事前登録（2026-10-17、最終回）
**動機**: H7 は「国間の右下がりは人口転換の進み具合の差」で止まり、先行指標（5 歳未満死亡率・女子就学率）がどの仕組みで TFR を動かすかを検証していない。part2 記事の末尾に書いた仮説 M1〜M4 を検証し、対抗仮説 M5 を加えて、段階（6→3 人、3→2 人未満）ごとに主役の仕組みを量つきで断定する。詳細: `docs/specs/growth-fertility-h8-mechanisms.md`。**注意**: H7 の結果を見た後に立てた仮説である。以下の推定量・判定基準は追加データを見る前に固定した。

**仕組みの候補**
- M1 保険としての多産の解消: 死亡率が下がると、望む数を得るための出生数が減る（望む数そのものは下げないので 2 人程度までしか説明できない）。
- M2 結婚の遅れ・減少: 女子の就学 → 自立した収入 → 晩婚・非婚 → 出産期間の短縮。
- M3 望む数の低下: 学歴が高いほど子育ての機会費用が高く、「数より質」を選ぶ。
- M4 M1 × M3 の相互作用: 子どもが確実に育つほど教育投資が報われ、学歴による望む数の差が大きくなる。
- M5（対抗仮説、設計時に追加）家族計画の普及: 教育は望む数ではなく避妊の知識・アクセスを通じて望まない出生を減らしているだけ。

**追加データ**: (1) DHS API を複数指標 × 内訳（Total / Education / Wealth quintile / Age 5-year）に拡張した新 mart `marts/dhs_mechanisms`（TFR・ASFR・wanted TFR・理想子ども数・これ以上望まない割合・U5MR・初婚年齢中央値・未婚率・結婚同棲中割合・女性の中等以上学歴割合・近代的避妊実行率）。(2) WDI に `smam_fe`（`SP.DYN.SMAM.FE`）, `wanted_tfr_wdi`（`SP.DYN.WFRT`）, `married_by18`（`SP.M18.2024.FE.ZS`）, `contraceptive_any`（`SP.DYN.CONU.ZS`）を追加。SMAM は出典混在のため、同一国 3 観測以上で国の中央値から 4 年以上離れた値を落とす（件数を報告）。

**検定と判定基準**（DHS の within 回帰は国 FE ＋ 調査年トレンド、SE は国クラスタ。学歴は女性本人の 4 群、勾配は Secondary − No education を主）
- **T1 望む／望まないの分解**（M5）: 隣接調査の組（間隔 ≥ 3 年、ΔTFR < 0）で s_w = ΣΔwanted / ΣΔTFR。s_w ≥ 0.6 → 望む数の低下が主（M5 は従）。≤ 0.4 → M5 支持。間は混合（M5 部分的支持）。
- **T2 死亡率**（M1）: (a) `ideal ~ ln u5mr + women_secondary_plus + FE + trend`、(b) `tfr − ideal ~ 同`、(c) `tfr ~ 同`。(c) の ln U5MR 係数 ≥ +0.25（CI 0 含まず）→ 支持。0.10–0.25 → 部分的支持。他 → 不支持。(d) U5MR < 40 の調査で TFR < 理想 の割合 ≥ 50% なら「M1 だけでは低出生率を説明できない」と書く。(a)/(b) の配分は記述。
- **T3 結婚**（M2）: (a) 初婚年齢中央値の学歴勾配 ≥ +2 年の調査の割合、(b) Bongaarts Cm = Σ m_a f_a / Σ f_a（結婚または同棲中 × ASFR）で first→last（≥ 8 年）の Δln TFR を Δln Cm と Δln(TFR/Cm) に分解、s_m = ΣΔln Cm / ΣΔln TFR、(c) `Cm ~ women_secondary_plus + ln u5mr + FE + trend`。(a) ≥ 70% かつ s_m ≥ 0.25 → 支持。(a) ≥ 50% かつ 0.10 ≤ s_m < 0.25 → 部分的支持。他 → 不支持。
- **T4 学歴勾配の在りか**（M3 vs M5）: 調査 × 学歴セルで `wanted_tfr = 調査 FE + 学歴`、`unwanted = tfr − wanted = 調査 FE + 学歴`。g_w ≤ −1.0（CI 0 含まず）かつ |g_w| ≥ 2|g_u| → M3 支持。g_w ≤ −0.5 かつ |g_w| > |g_u| → 部分的支持。|g_u| ≥ |g_w| → M3 不支持・M5 支持。M5 の最終判定は T1 と T4 の両方で支持なら支持、片方なら部分的支持。
- **T5 相互作用**（M4）: `wanted_tfr_{s,e} = 調査 FE + 学歴 + 学歴 × ln u5mr_s`。(γ_Sec − γ_None) > 0、CI 0 含まず、U5MR 150→30 で勾配の広がり ≥ 0.3 人 → 支持。符号正で CI 0 含む／広がり 0.1–0.3 → 部分的支持。他 → 不支持。
- **T6 2 人未満の段階**（全世界 WDI、10 年長期差分、国＋期間 FE）: `Δ₁₀tfr ~ Δ₁₀ln u5mr + Δ₁₀fem_sec_enrol + Δ₁₀smam_fe + Δ₁₀ln gdp_pcap_const` を区間開始 TFR ≥ 3 と < 3 で分けて標準化係数を比較。第 2 段階で絶対値最大（CI 0 含まず）の変数を主役と断定（初婚年齢 → M2、就学率 → M3、死亡率 → M1、所得 → 豊かさ）。全部 CI が 0 を含むなら「本データの変数では説明できない」と断定。欧州の学歴別 TFR・学歴別有配偶率、日本（H3b）は再掲のみ。

**最終仮説の文型**（事前固定）: 「6→3 人の段階は〔M1/M3/M5 のうち T1・T2・T4 で選んだ主役〕が担い、〔従〕は △割。3→2 人未満の段階は〔T6 の主役〕が □割を担う」。段階 1 の M1 と M3 の優劣は、T2(c) の係数 × 典型的な ln U5MR 低下幅と T4 の g_w × 典型的な中等以上学歴割合の上昇幅の比較で決める。

**頑健性（事前リスト、全部報告）**: DHS 調査のみ（MIS/AIS 除外）、隣接組 vs first→last、間隔 ≥ 8 年、U5MR 10 年版、中南米・南部アフリカ除外（Cm）、国ごと等加重、1990 年以降、学歴 2 群版。WDI: 5 年・20 年差分、SMAM 整形なし、`married_by18`、`contraceptive_any` 追加、2020–24 除外、産油国除外、人口 100 万未満除外、段階の境界 2.5 / 3.5。

**言えないこと（事前固定）**: 調査内の学歴差は自己選択を含む。理想・希望子ども数は事後の合理化を含む。Cm は「結婚または同棲」。DHS は低・中所得国のみ。識別戦略は固定効果・分解・調査内比較のみで、家族計画プログラムや規範の変化が同時に動きうる。

### H8b（事後追加 2026-10-18: 学歴群の中で望む数が下がった真因は何か）— H8 の結果を見た後に立てた追加検証
**動機**: H8 の E10 で、望む出生の低下の約 3 分の 2 は学歴構成の変化ではなく各学歴群の中（特に教育なし・初等）で起きた。ユーザーの仮説「学歴に関係なく、自分で働き収入を得る女性が増えたことが真因ではないか」を、対抗候補と並べて検証する。**事後追加**であり、以下の検定・判定基準は追加データ（DHS の就業・収入形態・子どもの就学指標）を見る前に固定した。結果は H8 の判定（M1〜M5）を変えず、「学歴群内の低下の説明候補」として別に報告する。

**候補**
- W（女性の就業・現金収入）: 学歴を問わず、働いて現金収入を得る女性が増えたことで子育ての機会費用が上がり、望む数が下がった。
- S（子どもの就学費用）: 子どもを学校に通わせるのが当たり前になり、親の学歴に関係なく子ども 1 人の費用が上がって「数より質」が進んだ。
- C（避妊・小家族規範の普及）: 家族計画プログラムと規範の普及で、学歴を問わず望む数が下がった（H8 の E10b で教育なし群の望む数が避妊実行率と並走していた）。
- U（死亡率）: H8 の T2/E4 の再掲。教育なし群では E10b で関連なし。

**追加データ**（DHS API、`H8_REQUESTS` に追加、mart `dhs_mechanisms` に metric 追加）: `women_employed`（`EM_EMPL_W_EMC`、過去 12 か月に働き現在も働いている女性の割合、Total / Education / Wealth quintile、262 調査・76 か国・1994–2024）、`married_employed`（`EM_EMPM_W_EMP`、既婚女性の過去 12 か月就業率、Total、254 調査）、`married_cash_only` / `married_cash_inkind`（`EM_ERNM_W_CSH` / `EM_ERNM_W_CAK`、就業した既婚女性のうち現金のみ／現金＋現物で報酬を得た割合、Total、204 調査）、`child_primary_attendance` / `child_secondary_attendance`（`ED_NARP_B_BTH` / `ED_NARS_B_BTH`、子どもの初等・中等純就学率（世帯調査）、Total、182 調査・68 か国・1999–）。派生: `married_cash_employed = married_employed × (married_cash_only + married_cash_inkind) / 100`（現金収入のある既婚女性の割合）。

**検定（H8 と同じ枠: 国 FE ＋ 調査年トレンド、国クラスタ SE、標準化係数）**
- **X1 教育なし群の望む数の horse race（主）**: 教育なしセルの `wanted_tfr` を被説明変数に、同じセルの `women_employed`（教育なし）、`modern_contraception_married`（教育なし）、調査 Total の `child_primary_attendance`、`child_secondary_attendance`、ln U5MR を同時に入れる（すべてそろう調査）。各変数を 1 本ずつ入れた版も併記。
- **X2 調査全体の horse race**: Total の `wanted_tfr` を、`married_cash_employed`、`women_employed`、`child_*_attendance`、`modern_contraception_married`、ln U5MR、`women_secondary_plus` で同様に。
- **X3 first→last の変化の対応**: 教育なし群の Δwanted と、Δ`women_employed`（教育なし）・Δ`child_primary_attendance`・Δ`modern_contraception_married`（教育なし）の国レベルの相関（Spearman）。
- **X4 調査内の媒介**: 調査 × 学歴セルで、`wanted_tfr` の学歴勾配 g_w（H8 T4）に `women_employed` のセル値を加えたとき g_w がどれだけ縮むか。就業の学歴勾配も報告。
- **X5 就業率そのものの推移**: 教育なし群の `women_employed` は first→last でどう変化したか（上がっていなければ W は成り立たない）。

**判定（事前固定、X1 を主）**: X1 で標準化係数の絶対値が最大で CI が 0 を含まない変数を「教育なし群の望む数と最も強く並走する候補」とする（就業 → W、子どもの就学率 → S、避妊 → C、ln U5MR → U）。CI が 0 を含まない変数が無ければ「どの候補も確かめられない」と断定する。W が選ばれるには、X5 で教育なし群の就業率が中央値で上昇していることも必要（上昇していなければ「W は成り立たない」）。X2〜X4 は整合性の確認として報告し、X1 と食い違えば「候補は絞れない」と書く。
**頑健性**: `married_cash_employed` を `women_employed` の代わりに（X2）、初等／中等就学率の片方ずつ、1999 年以降、DHS 調査のみ、国ごと等加重。
**言えないこと**: 就業・就学・避妊はいずれも家族計画プログラムや経済発展と同時に動くので、並走は因果ではない。就業は「働く必要（貧困）」も含む。DHS の就業指標は 1994 年以降で、1990 年代前半以前の変化は見えない。
