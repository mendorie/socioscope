# spec: スポーツ車市場へのドリルダウン（bicycle-industry、R5〜R7）

作成 2026-10-22。R1〜R4 の結論（台数の不況・金額の成長、先食いの形と埋まらない穴、欧州の高額 e-bike 在庫、スポーツ車は公的統計で分離不能）を受け、スポーツ車に絞って「上場企業の開示」と「需要側の公的統計」を束ねる。各フェーズは PR 単位で、仮説は分析前に `design/themes/bicycle-industry.md` に事前登録する。

## 前提（割り切り）
- 「スポーツ車の売上」を単独開示する上場企業は無い。完成車（Giant・Merida）、部品（シマノ・KMC・Fox）、小売（Bike24・Halfords）をセグメントか全社で読む。
- 「セール（値引き率）」の公開統計は無い。小売の粗利率（Bike24・Halfords）が最も近い観測。
- 日本のスポーツ車台数は JBPI（メンテ中）が戻るまで取れない。JBPI は Phase 4 に置く。
- コロナ前（〜2019）・特需（2020–22）・特需後（2023〜）の 3 局面で報告する。

## Phase 1 — 世界のスポーツ車サイクル（部品 → 完成車 → ハイエンド）: R5
- ソース（キー不要、機械取得）:
  - UN Comtrade: 台湾（490）の完成車輸出（8712・871160）の仕向地別（日・米・独・蘭・英・世界）台数・金額 2015–2024。台湾は非電動スポーツ車の世界工場なので、世界のスポーツ車需要の最良の代理。
  - TWSE / MOPS: Giant 9921・Merida 9914・KMC 5306 の月次売上（2013〜）。
  - SEC EDGAR: Fox Factory の Specialty Sports Group（自転車）セグメント売上（四半期、XBRL か 10-K）。
  - 既存: シマノ 自転車部品（年次）。
- 仮説（事前登録、計算前に固定）:
  - H9: 世界のスポーツ車需要（台湾の完成車輸出台数）は特需後（2023–24）にコロナ前（2015–19 平均）を下回るが、金額（USD）では上回る（高額化）。判定: 台数比 < 0.9 かつ 金額比 > 1.1 で整合。
  - H10: 在庫サイクルの位相は 部品（シマノ・KMC）→ 完成車（Giant・Merida）→ ハイエンド部品（Fox）の順にピークが来て、谷の深さは上流ほど深い。判定: 月次売上の 12 か月移動平均のピーク月が 部品 ≤ 完成車 の順で、ピークからの最大落ち幅が 部品 > 完成車 なら整合。
- 成果物: `comtrade.py` 拡張（reporter 490 × 仕向地）、`tw_mops.py`（月次売上）、`edgar.py`（Fox）、R5 report。

## Phase 2 — 需要側の構造: R6
- ソース: 総務省 社会生活基本調査（2011・2016・2021、e-Stat）: サイクリングの行動者率・行動者数を性・年齢階級別。補助: 笹川スポーツ財団 スポーツライフ・データ（隔年、PDF）、日本雑誌協会 印刷証明付部数（サイクルスポーツ・BiCYCLE CLUB）。
- 仮説（事前登録）:
  - H11（高齢化・非補充）: サイクリングの行動者率は 2011 → 2021 に 20–30 代で低下し、50–60 代で上昇または横ばい。行動者の年齢中央値は上がる。判定: 20–39 歳の行動者率の変化 < 0 かつ 50–69 歳の変化 ≥ 0 で整合。
  - H12: 雑誌部数は特需期に一時増え、特需後はコロナ前を下回る（関心の先食い）。判定: 2023–24 平均 / 2017–19 平均 < 0.9 で整合。
- 成果物: `shakai_seikatsu.py`（e-Stat xlsx）、`jmpa.py`（部数、HTML）、R6 report。

## Phase 3 — 欧米小売の粗利・在庫とコロナ前基準線: R7
- ソース: Bike24（四半期: 売上・粗利率・在庫）、Halfords（Cycling 売上）、Merida 年報の Specialized 持分法損益、Dorel Sports セグメント（2010–2020）、Accell 年報（2015–2021）。PDF 中心。
- 仮説（事前登録）:
  - H13（セールは粗利率に出る）: Bike24 の粗利率は特需期より特需後に低く、在庫回転は遅い。判定: 2023–24 の粗利率平均 − 2021–22 平均 ≤ −2pt で整合。
  - H14: Specialized（Merida 持分法）の利益は特需後に赤字または特需期の 3 割以下。
- 成果物: `halfords.py`・`accell.py`（PDF）、`merida.py`、R7 report（`bike24.py` は取り下げ）。

### Phase 3 の調査結果（2026-10-22）と判断待ち
- **Merida 年報・四半期財報**: 自社 IR ページ（merida-bikes.com、robots 許可）から PDF にリンクするが、PDF の実体はすべて `merida-cdn.m-c-g.net` にあり、その robots.txt は全面 Disallow。FY2015–2022 は自社サイトに無く MOPS/doc.twse（同じく Disallow）だけ。→ **H14（Specialized の持分法損益）は現行ルールでは取得不可。** 到達性確認で読めた FY2023・2024 の値（SBC の持分法損失、関連当事者売上の比率）は manifest 無しのため mart に入れない。CDN の robots を「資産ホストの一般設定」として例外扱いにするかは人の判断（設計判断 → ADR 候補）。
- **Bike24**: IR サイトは EQS の SPA で、API は JWT 認証（クライアント側で発行）。鍵なし取得は不可で、トークンの再現は認証回避に当たるので行わない。→ **H13（粗利率）は取得不可。** ブラウザで PDF URL を取るなら人の作業。
- **Halfords**: 取得可（robots 許可、プレリリース PDF FY15–FY26）。Cycling は FY25 以降に £m、FY19–24 は Retail 売上 × 構成比で導出。粗利率は開示なし。→ 英国小売の Cycling 売上の 3 局面は出せるが、H13 の代替にはならない。
- **Accell**: 本体サイトに年報なし、年次マイクロサイトは消滅。Wayback で完全なのは 2017（EN）・2018（NL、章別）・2021（EN、2017–2021 の 5 年表）。2015・16・19・20 は 1 MB で切れている。→ コロナ前基準線は 2017–2021 の売上のみ。
- 判断: H13・H14 は取り下げ候補。Halfords（Cycling 売上）と Accell（2017–2021 売上）だけで R7 を書く価値は限定的（英国小売の 3 局面、欧州 e-bike メーカーの特需前後）。JBPI（Phase 4）の復旧と SEC 連絡先（Fox）の方が優先度が高い。
- **判断の結果（2026-10-22）**: ユーザーが `merida-cdn.m-c-g.net` を公開開示文書の例外として承認 → ADR 0006。H14 を R7 として実施。H13（Bike24）は取り下げ。Halfords・Accell は未着手（任意）。

### Phase 3 の結果（R7、2026-10-22）
- `themes/bicycle-industry/reports/2026-10-22-r7-specialized.md`。H14 (a) 整合: Merida が認識した持分法損益（関連企業全体。SBC 単独は開示なし → 事前登録からの逸脱として記録、SBC は関連企業帳簿価額の 98%）は FY2022 +624 百万 NT$ → FY2023 −685、FY2024 −4,065、FY2025 +92（FY2022 の 14.8%）。(b) 整合: SBC 集団向け売上 FY2022 → 2025 −42.4%、全体 −27.7%、SBC 以外 +4.1%。
- 補足（Halfords・Accell、2026-10-22 追加、記述のみ）: Halfords Cycling 売上（FY2019 = 100）は特需 FY2021 145 → 特需後 FY2023–26 平均 94、FY2026 98。コロナ前は年率 +7.0%。Accell は 2019 → 2021 +24、以降観測不可。
- 所見: 上場 OEM（Giant・Merida）が「2019 年末未満の売上」で止まっているのに対し、Specialized は 2 年連続の損失と帳簿価額の減少（FY2024 −2,883 百万）というより深い調整を示す。ただし尺度が違い、1 社 1 系列。

## Phase 4 — 日本のスポーツ車本丸（JBPI 復旧後）: R8
- JBPI 国内向自転車生産輸入統計（車種別、月次 2018〜）と POS。R4 の先食い検定（E/F/R・L）をスポーツ車に適用、H2 を判定。

## 順序と判断
1 → 2 → 3 → 4。各フェーズで、ソース到達性の調査 → 事前登録 → 結線（TDD）→ 分析 → methodology-reviewer → PR → マージ。到達できないソースはフェーズ内で代替（例: MOPS 月次が取れなければ年報の年次売上）し、設計書に記録する。
