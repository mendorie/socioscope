## 0. 問いと、この記事が出す「答えの形」

### 問い（1 文）
**国と国を比べたとき「豊かな国ほど出生率が低い」という右下がりは、何によって生じているのか。**

### 出発点の仮説（元記事の総括より）
右下がりの正体は豊かさそのものではなく、子どもの死亡率が下がり、女子が学校に行くようになったという **人口転換の段階の違い** である。

### 答えの候補（事前に 3 つに絞る）
記事の見出しになりうる答えを、データを見る前に 3 つに固定する。分析はこの 3 つのどれを選ぶかを決めるために設計する。

| 記号 | 答え | 要するに |
|---|---|---|
| **A** | **豊かさの差そのものが出生率の差を作っている** | 段階をそろえても所得差は残って効く。転換が終わった国の間でも豊かな国ほど少ない |
| **B** | **人口転換の「進み具合」の差が出生率の差を作っていて、豊かさはそれと一緒に動いているだけ** | 転換が終わった国の間では所得差は効かない。転換は豊かさの閾値で始まっていない。同じ国の中では死亡率低下・教育拡大が出生率低下を伴い、所得の伸びは伴わない |
| **C** | **豊かさが人口転換を引き起こし、転換が出生率を下げている（豊かさは上流にある）** | 段階をそろえると所得差は消えるが、転換の開始は所得の一定水準で起き、同じ国の中で所得の伸びが死亡率低下・教育拡大・出生率低下に先行する |

元記事の H4 は A と B/C を分ける手前（「段階をそろえると縮む」）で止まり、B と C を区別する検定（媒介か交絡か）をしなかった。ゆえに「重なる」「別のことが起きている」という曖昧な言い方になった。**今回は B と C を分ける検定（転換開始時の所得のばらつき・同じ国の中の時間順序）を主役にする。**

### 「クリアな結論」のための執筆規律（事前に決める）
1. 見出しと要約の第 1 文は **A/B/C のどれか（または「主に B、残り X 割は C」のような量つきの混合）** を断定形で書く。「言えない」「分からない」を第 1 文に置かない。
2. 判定は §3 のスコアカードで機械的に決める。結果を見てから判定基準を動かさない。
3. 限界は「結論を覆しうる条件」に限って 3 項目以内で書く。結論を薄める注釈（「ただし関連であって…」）は 1 回だけにまとめる。
4. 因果語の扱い: 「何が差を作っているか」という問いへの答えは、本プランの識別戦略（固定効果・長期差分・イベント時間整列・転換開始時点の分散）の範囲で **「最も整合的な説明」として断定する**。「因果を証明した」とは書かないが、「整合的な説明は一つに絞れた」とは書く。

### 転換開始年の定義（事前固定。TFR で層別はしないが、開始年の特定には TFR を使う）
- 対象: 1960–1975 の TFR 最大値が 4.5 以上の国（転換前とみなす）。
- 開始年 = 最大値から **10% 下回り、その後二度と戻らない最初の年**（Coale の 10% 基準の変形）。
- 既存 mart での試算: 216 か国中 157 が対象、**155 で開始年が特定**（中央値 1975、四分位 1969–1987、最遅 2023）。
- 「1960 年に転換済み」の層（TFR 最大値 < 4.5、約 60 か国）は別層として扱い、開始時所得の分析（T3）には入れない。
- 頑健性: 閾値を 4.0 / 5.0、低下率を 15% に替える。

## 3. 検定の設計（T1〜T6）とスコアカード

全検定は `analysis/a20261019_h7_between_gradient.py`（仮）で決定的に実行し、各検定の判定を標準出力に出す。SE は国クラスタ。

### T1. 国間勾配の順序非依存な分解（Gelbach 分解）
- 推定: H4 と同じ同一サンプル（1990–2024、段階指標 listwise）。基本式 `tfr ~ ln_gdp + C(year)` の係数 β₀ と、段階指標を全部入れた β_full の差 β₀ − β_full を、各段階指標 k の **寄与 δ_k = Γ_k × β_k**（Γ_k: 指標 k を ln_gdp に回帰した係数、β_k: 全部入れた式の指標 k の係数）に分解する。Σδ_k = β₀ − β_full が厳密に成り立ち、投入順序に依存しない。
- 出力: 「−0.94 のうち、死亡率 x、女子教育 y、平均余命 z、都市化 w、女性就業 v、残り（所得そのものに残る分）r」の 1 本の積み上げ棒。
- **判定**: 段階指標の合計寄与の割合 S = Σδ_k / β₀。S ≥ 0.6 → B または C に 1 点。S < 0.4 → A に 1 点。0.4–0.6 → 点なし（混合と記述）。
- 注: 媒介と交絡は区別できない。T1 は「A か、B/C か」を分ける検定であり、B と C は分けない。

### T2. 転換が終わった国の間に、所得勾配はあるか（複合段階で測り直す）
- 段階の複合指標: 5 歳未満死亡率（対数）・平均余命・女子中等就学率の **第 1 主成分**（同一サンプルで固定。符号は「転換が進むほど大きい」に揃える）。H4(c) で死亡率だけで切ると途中の層に −0.3〜−0.5 が残った問題に対応する。
- 層: 複合指標の五分位（事前固定。結果を見て切り直さない）。各層内で `tfr ~ ln_gdp + C(year)`。
- **判定**: 最上位層（転換が最も進んだ 20%）の勾配の 95% CI が 0 を含み、点推定の絶対値 ≤ 0.20 → B/C に 1 点。CI 上限 < 0 かつ点推定 ≤ −0.30 → A に 1 点。
- 補助: 「転換開始から 30 年以上経った国」だけの層でも同じ回帰（開始年ベースの層別）。
- 残差の扱い: 途中の層に残る負の勾配は、その大きさを **「転換の速さが所得と相関している分」** として T4 で説明を試みる。

### T3. 転換は豊かさの閾値で始まるのか（B と C を分ける検定 その 1）
- 対象: 開始年が特定できる 155 か国。開始年の一人当たり GDP（2015 年固定 US$）の分布。
- 出力: 開始時所得のヒストグラム、p10/p90 比、開始年と開始時所得の散布（Bongaarts–Watkins 1996 の「後から転換した国ほど低い発展水準で始める」の再現）。
- **判定**: p90/p10 ≥ 5（5 倍以上ばらつく） → B に 1 点。p90/p10 ≤ 2.5（狭い帯に集中） → C に 1 点。間は点なし。
- 補助: 開始時の 5 歳未満死亡率の p90/p10 を並べ、「所得より死亡率のほうが開始時に揃っている」かを比較する（死亡率の比が所得の比より小さければ B の傍証）。
- 補助 2: 開始年を被説明変数に、1960 年時点の ln GDP と同一地域の先行転換国の割合（拡散の代理）を説明変数にした横断回帰（記述）。

### T4. 同じ国の中で、何が何に先行するか（B と C を分ける検定 その 2、主検定）
- (i) **イベント時間整列**: 開始年を 0 として −20..+40 年の ln GDP（固定 US$）、5 歳未満死亡率（対数）、女子就学率、TFR の **国平均軌跡**（各国の 0 年値からの差分）を描く。C なら所得の伸びが −20..0 で加速し、B なら所得の伸びは 0 の前後で変わらず、死亡率が −20..0 で下がる。
- (ii) **開始前後の成長率比較**: 各国の −10..0 と 0..+10 の年平均所得成長率、および同時期の世界平均との差。開始前 10 年の成長率が世界平均より高い国の割合。
- (iii) **10 年長期差分**: `Δ₁₀ tfr = a·Δ₁₀ ln_gdp + b·Δ₁₀ ln(u5mr) + c·Δ₁₀ fem_enrol + 国 FE + 期間 FE`（1960–2024、重ならない 10 年区間）。年次 within（H1/H2）で ≈ 0 だった所得が、数十年単位でも ≈ 0 かを確かめる。
- (iv) **先行関係**: Δ₁₀ ln(u5mr) と Δ₁₀ ln_gdp の各ラグ（前の 10 年）を同時に入れ、どちらの前期変化が今期の ΔTFR を予測するか。
- **判定**（(i)〜(iv) をまとめて 1 点）: 「開始前 10 年の所得成長率が世界平均を上回る国が 50% 以下」かつ「(iii) で死亡率・教育の係数が所得の係数より大きい（標準化）」 → B に 1 点。「上回る国が 70% 以上」かつ「(iv) で前期の所得変化が ΔTFR を予測し、死亡率の前期変化は予測しない」 → C に 1 点。
- 既知の弱点: 途上国の WDI TFR は推計で平滑。10 年差分はそれでも方向を保つが、1〜2 年の先行・遅行は読まない。

### T5. 豊かさは必要でも十分でもないか（反例を数える）
- 1960→2024（固定 US$ があれば 1960、無ければ最初の観測年から）の所得倍率と TFR 低下幅で国を 4 象限に分ける。閾値は事前固定: 所得「伸びた」= 3 倍以上、TFR「下がった」= 2.0 以上の低下。
- 出力: 「豊かにならずに下がった国」（例として想定: バングラデシュ、ネパール、イラン、ケニア等）と「豊かになったのに下がらなかった国」（産油国が中心と想定）の **一覧と件数**、および各群の死亡率・教育の変化。
- **判定**: 両方の象限にそれぞれ 10 か国以上あり、かつ「豊かにならずに下がった国」の死亡率低下幅の中央値が全体の中央値以上 → B に 1 点。「豊かにならずに下がった国」が 5 か国未満 → C に 1 点。
- この検定は記事では最も直観的な証拠になる（「国名で語れる」）。

### T6. 逆の向き: 転換が所得を押し上げたか（記述のみ、点なし）
- T4(i) のイベント時間軌跡で、開始後 +10..+30 年の所得成長率が開始前より高いか。人口ボーナスの記述的確認。
- 記事では「右下がりの一部は『少なくなったから豊かになった』という逆向きの流れも含む」と書くための材料。点数には入れない（識別できないため）。

### スコアカードと答えの決め方（事前固定）
| 検定 | A | B | C |
|---|---|---|---|
| T1 分解 | S < 0.4 | S ≥ 0.6 | S ≥ 0.6 |
| T2 転換後の層 | 負で有意 | ≈ 0 | ≈ 0 |
| T3 開始時所得 | — | p90/p10 ≥ 5 | ≤ 2.5 |
| T4 順序 | — | 死亡率・教育が主、所得は先行せず | 所得が先行 |
| T5 反例 | — | 両象限 ≥ 10 | 「豊かにならず低下」< 5 |

- 最多得点の答えを見出しにする。**同点または 1 点差のときは「主に X、ただし Y の要素が △割」と量で書く**（T1 の S と T2 の残差勾配で「割合」を定量化する）。
- どの答えにも 2 点以上つかない場合のみ「3 つの説明のどれとも合わない」と書き、何が合わないかを具体的に書く。「分からない」とは書かない。

### 見出し文のテンプレート（結果を見る前に用意する）
- B が選ばれた場合: 「豊かな国ほど子どもが少ないのは、豊かさのせいではなく、子どもが死ななくなり女子が学校に行くようになった **時期が国によって違う** からだった。転換は所得の水準を待たずに始まり、転換が終わった国の間では、豊かさの差は出生率と無関係だ。」
- C が選ばれた場合: 「豊かな国ほど子どもが少ないのは、やはり豊かさが起点だった。ただし豊かさは直接ではなく、子どもの死亡率の低下と女子教育の普及を通じて効く。転換は所得がある水準に達した国から順に始まっていた。」
- A が選ばれた場合: 「段階をそろえても、転換が終わった国の間でも、豊かな国ほど子どもは少ない。人口転換では説明しきれない『豊かさそのもの』の効果が残る。」
- 混合の場合: 「右下がりの 8 割は人口転換の進み具合の差で説明でき、残り 2 割は転換の途中で豊かな国ほど転換が速く進んでいることによる。転換が終わった国の間では、豊かさの差は効かない。」（数字は結果で置換）

## 4. 頑健性（事前リスト。全部報告する）
- サンプル: 産油国除外（H1 の `OIL_STATES`）、人口 100 万未満除外、2020–24 除外、小国（人口 10 万未満）除外。
- 転換開始の定義: 閾値 4.0 / 5.0、低下率 15%、開始を「5 年移動平均」で判定。
- 所得系列: PPP（1990–）と固定 US$ の両方で T1/T2 を推定し、同一期間で比が揃うことを確認。
- 段階の複合指標: 主成分の代わりに死亡率のみ（H4 再現）、三指標の単純標準化平均。
- T4 の差分幅: 5 年・20 年。
- 分解（T1）: 段階指標 4 本版（就学率なし、n ≈ 6,000）。

## 5. 言えないこと（事前固定。記事では 3 項目以内に圧縮）
- イベント時間整列と長期差分は **順序** を示すが、「死亡率低下が出生率低下の原因」を証明しない（第三の要因＝家族計画プログラム、宗教・文化の変化、政策が両方を動かしうる）。
- 転換開始時所得のばらつきは「所得の閾値がない」ことを示すが、「所得が無関係」とは言えない（開始後の速度には効きうる。T2 の残差勾配で定量化する）。
- 1960 年に転換済みだった国（欧州・日本・北米）の転換開始は本データの外。これらの国の「豊かさと出生率」は T2 の最上位層としてのみ扱う。
- TFR 推計系列の平滑化により、途上国の年単位のタイミングは信用しない（10 年単位のみ）。
