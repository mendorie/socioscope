## 1. 問い
人口当たりの議員数（および人口規模を補正した議員数）は、国ごとの「政府の大きさ」の選択と関係しているか。
ユーザーの素朴な疑問: 「小さな政府」の国は議員も少なく、「大きな政府」の国は議員も多い、という対応があるのではないか。

R10 までに分かっていること（事前の見立ての根拠）:
- 人口当たり議員数は人口規模にほぼ機械的に決まる（立方根法則、R1）。米国が最少で北欧が最多なのは、主に人口規模の効果。
- 人口当たり公務就業者と人口当たり議員数は同じ向き（ρ = +0.33、R10）で、代替関係ではない。これも規模の効果で説明できる可能性が高い。
- 議員が少ない国ほど議員 1 人当たりの職員・予算が多い（R5、ρ = −0.42 / −0.62）。

事前の見立て: **人口規模を補正すると、議会の大きさと政府の大きさの相関はほぼ消える**（両者は別の次元の選択）。見立てと逆の結果が出ても、そのまま報告する。

## 2. 仮説と判定基準（結果の計算前に固定。着手時に設計書へ写す）
「政府の大きさ」の主指標は **一般政府支出の対 GDP 比**（最も標準的な定義）。補助指標として税収対 GDP 比と公務就業者比率（R10 と同じ）。
「議会の大きさ」は 2 通り: (i) 人口 100 万人当たりの下院定数（素の比率）、(ii) 立方根法則で補正した比 `statutory_seats / population^(1/3)`（R1 の H1c と同じ）。

| 仮説 | 内容 | 判定基準（OECD 下院、スピアマン順位相関 ρ） |
|---|---|---|
| **H15a** | 素の人口当たり議員数は政府支出対 GDP 比と正の相関を持つ（「大きな政府ほど議員が多い」が素の比率では見える） | ρ ≥ +0.3 で整合、|ρ| < 0.3 で不支持 |
| **H15b** | 立方根法則で補正すると、その相関は消える（見立ての本体） | 補正後 |ρ| < 0.2 で整合（規模の効果だった）、|ρ| ≥ 0.3 で不支持（政府観の効果が残る）、間は中間 |
| **H15c** | 補正後も関係が残る場合、その向きは正（大きな政府ほど議会も大きい）であり、負（行政が大きいと議会は小さくてよい、R10 のユーザー仮説の支出版）ではない | H15b が不支持のときのみ判定。ρ の符号で記述 |
| **H15d** | 議員 1 人当たりの議会職員数（R5）は政府支出対 GDP 比と無関係（議会の執行力の配分は政府観とは別） | |ρ| < 0.3 で整合 |

判定はすべて記述統計で、因果は主張しない（政府の大きさも議会の大きさも、歴史・連邦制・人口規模の共通原因を持つ）。

## 4. 方法
1. OECD 38 か国の下院について、(i) 素の比率と (ii) 立方根補正比を作る（R1 のコードを再利用）。
2. 政府支出対 GDP 比（一般政府、2019〜2023 平均）と、それぞれのスピアマン順位相関を出す（R5 の `spearman` を再利用）。
3. 補正の別法として、`log(定数)` を `log(人口)` に回帰した残差を使っても同じ結論になるか確認する（立方根の係数 1/3 を仮定しない版）。
4. 層別: 連邦制／単一制、人口 1,000 万人以上／未満、両院制／一院制。米国は人口効果が極端なので、米国を除いた値も併記する。
5. 散布図 2 枚（素の比率 × 支出比、補正比 × 支出比）。国名ラベル付き。
6. 図は `reports/figures/r16_*.png`、スクリプトは `analysis/a<yyyymmdd>_r16_government_size.py`（決定的、2 回実行して stdout 一致）。

## 5. 落とし穴（事前に書いておく）
- **規模の交絡が本体。** 素の比率で正の相関が出ても、それは「小国は政府も議会も人口比で大きい」である可能性が高い。H15a と H15b を分けたのはそのため。
- **連邦制。** 米・独・加・豪・スイスでは州議会議員が多数おり、国会議員だけを数えると議会の大きさを過小評価する。同様に中央政府支出だけを数えると政府の大きさも過小評価する。一般政府ベースの支出を使い、連邦制で層別する。州議会議員の合算は番外編の範囲外（データ整備が重いので、限界として書く）。
- **COVID 年。** 2020〜2021 年の支出比は一時的に跳ねる。複数年平均と 2019 年単独の両方で見る。
- **IPU は非商用。** 番外編の記事も非商用の範囲で扱う（本編と同じ）。
- **OECD 38 か国は n が小さい。** |ρ| = 0.3 は 5% 有意水準に届かない（n = 38 で有意境界は約 0.32）。判定基準は効果量で置き、p 値は参考として併記する。
- **「小さな政府」は支出比だけでは測れない**（規制の強さ、公営企業の範囲）。本書では支出比・税収比・公務就業者の 3 つで三角測量し、それ以上は言わない。
