## 「作りやすくなった」の証拠（Q3 の前提の検証）

### 反証・限定（事実）
- METR RCT（2025-07-10）: 経験豊富な OSS 開発者 16 名・246 課題で、AI 使用時は**19% 遅く**（95%CI +2〜+39%）。開発者は事後も 20% 速くなったと信じていた [METR](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/)。2026-02-24 の追試は −18%（CI −38〜+9%）だが選択バイアスで「非常に弱い証拠」[METR](https://metr.org/blog/2026-02-24-uplift-update/)。
- DORA 2024（2024-10-23）: AI 採用 25% 増 → スループット −1.5%、デリバリー安定性 −7.2% [Google Cloud](https://cloud.google.com/blog/products/devops-sre/announcing-the-2024-dora-report)。Uplevel（2024-10、約 800 名）: サイクルタイム有意差なし、バグ 41% 増 [Uplevel](https://uplevelteam.com/blog/ai-for-developer-productivity)。

- 単位経済: Bessemer は Supernova 群の平均粗利を約 25%（負のことも）、低スイッチングコストゆえ「脆い」リテンションと記述 [BVP](https://www.bvp.com/atlas/the-state-of-ai-2025)。Cursor は 2025-06 の料金改定で謝罪 [TechCrunch](https://techcrunch.com/2025/07/07/cursor-apologizes-for-unclear-pricing-changes-that-upset-users/)、GitHub Copilot も 2026-06-01 からトークン課金に移行し反発 [TechCrunch](https://techcrunch.com/2026/05/30/what-a-joke-github-copilots-new-token-based-billing-spurs-consternation-among-devs/)。

### 解釈
- 「プロトタイプ・単機能アプリを作る」コストが下がったことは、採用率・ARR 到達速度・YC のコードベース構成から支持できる。一方「熟練者のスループット」や「品質」が上がった証拠は弱いか逆（METR・DORA・Uplevel）。
- Q3 の前提は「**模倣が速く安くなった**（機能の差分が消えやすい）」という形では成立する。「開発生産性が全面的に上がった」という形では成立しない。本ノートではこの限定付きで Q3/H5 を評価する。
- 作りやすさは**巨大資本側にも**等しく効く（Copilot Free・Firebase Studio・GitHub Spark の投入速度）。参入障壁の低下はスタートアップ側の優位ではなく、両側の「機能」の価値を同時に下げる。

## Cursor（Anysphere）vs GitHub Copilot ― 暫定: 成功（ただし独立は維持せず）

### Takeaway
2 年で ARR $0→$1B 超、Microsoft（GitHub）が無料枠・エージェント・自社モデルで追随しても首位級を維持した。しかし 2026 年に計算資源（compute）制約を理由に SpaceX へ全株式交換で売却（報道）。堀として機能したのは「最速で出し続ける力（SPEED）」と「エディタ内のワークフロー（SC-WF）」で、モデル優位ではない（Composer は GPT-5/Sonnet 4.5 に劣ると自認）。一方、上流のモデル提供者（Anthropic・OpenAI）が同じ市場で競合する **F-PLATFORM の新型**にさらされ、資本差ではなく compute 差で独立を手放した。

### Inferences
- 主 MOAT: **SPEED**（モデル非依存で UX を先行投入し続けた）＋ **SC-WF**（エディタ＝毎日の作業面。VS Code フォークで既存拡張を引き継ぎ移行コストを下げつつ、自社側では codebase index・rules が蓄積）。副: BRAND（開発者コミュニティでの口コミ）。
- モデル優位（NE-DATA/CR としてのモデル）は堀ではなかった: Composer は最先端に劣ると自認し、売上の大半は他社モデルの再販。H5 の「モデル優位は弱まる」と整合。
- 新しい失敗圧力: 上流モデル提供者が同じ製品（Claude Code・Codex）を出し、API を止めうる（Windsurf 事例・OpenAI の Cursor 遮断報道）。これは**F-PLATFORM（供給側）の新型**。Cursor はこれを自社モデルと compute 確保（SpaceX）で回避した。資本差ではなく「GPU へのアクセス差」が独立存続を決めた点が従来事例と異なる。
- 判定「成功（暫定）」の根拠: 巨大資本参入後もカテゴリ上位 2 位を維持し、売上は拡大、買収は「首位のまま高倍率」。ただし 2 年未満の観察。

### Gaps
- Microsoft の GitHub/Copilot 売上の一次発言、Cursor の監査済み数値、SpaceX 買収後の ARR。SpaceX 買収は複数の TechCrunch 記事に依拠するが、他紙で未確認。

## Windsurf（Codeium）― 対照事例: 混合（分割売却）

### Takeaway
Cursor と同じカテゴリ・同時期で ARR $100M 到達目前（2025-04）まで行きながら、OpenAI 買収（$3B）が Microsoft の IP 条項で崩れ、Anthropic が Claude 供給を遮断、Google が創業者と約 40 名を $2.4B で引き抜き（ライセンス）、残りを Cognition が約 $250M で取得。**モデル提供者の方針で供給・流通を断たれる F-PLATFORM 新型**の最も明確な例。

### Cited Findings
- Series C $150M・$1.25B（2024-08-29）[TechCrunch](https://techcrunch.com/2024/08/29/github-copilot-competitor-codeium-raises-150m-at-a-1-25b-valuation/)。ARR 約 $40M（2025-02）→ 約 $100M（2025-04）、Cursor 対抗の値下げ [TechCrunch](https://techcrunch.com/2025/04/23/windsurf-slashes-prices-as-competition-with-cursor-heats-up/)。
- OpenAI が約 $3B で買収合意（Bloomberg、2025-05-06）。Anthropic が 5 日未満の通告で Claude 直接アクセスを遮断、「OpenAI に Claude を売るのは奇妙」（Kaplan、2025-06-05）[TechCrunch](https://techcrunch.com/2025/06/05/anthropic-co-founder-on-cutting-access-to-windsurf-it-would-be-odd-for-us-to-sell-claude-to-openai)。

### Inferences
- 直接原因: **F-PLATFORM（モデル供給遮断）** ＋ 買収交渉の崩壊。製品・ARR では Cursor に数か月遅れの 2 位で、F-COPY ではない。
- 投資家は 4 倍で回収しており「失敗」ではなく「混合」。だが独立企業としてのカテゴリ競争からは脱落。

### Gaps
- Cognition 傘下での Windsurf 単体売上。

## Lovable / Bolt.new / Replit vs Vercel v0・Google・OpenAI・GitHub Spark ― 暫定: 成功（Lovable・Replit）／不明（Bolt）

### Takeaway
「作りやすさ」そのものを売る企業群。Lovable は 8 か月で $100M ARR、2026-09 に $600M ARR、Replit は 9 年の低迷後 2025 年に $10M→$150M 超。巨大資本側（Vercel v0・Firebase Studio・GitHub Spark・Codex）が同等機能を出しても成長は続いた。ただし Bolt は 2025-03 の $40M ARR 以降公開数値が途絶。粗利は低く（Lovable 36%、Replit −14→23%、いずれも推計）、観察される堀は**非開発者という新市場への先行（CP 的）＋ホスティング・DB・認証まで含めた「製品を出す」ワークフロー（SC-WF）**で、モデルではない。

### H5 への中間所見（判定は report 側で行う）
- 「モデル・アルゴリズム優位のみ」を堀とした企業: Jasper（FT モデル）、Inflection、Stability、Character.ai、Grammarly（校正精度）、Chegg（独自 Q&A は公開クロール可）→ いずれも 3 年以内に失速・売却・吸収。**反例候補は ElevenLabs と Midjourney**だが、両社とも自社モデル**単独**ではなく CR（閉じたモデル＋人材）＋ SC-WF／BRAND の組合せで、「モデル優位のみ」には該当しないと読める。現時点で H5 を覆す例は見当たらない（ただし観察期間 4 年未満）。
- 残っている企業の共通項: SC-WF（Cursor・Harvey・Glean・Calendly・Lovable）、CP（横断中立: Otter・Granola・Lovable）、BRAND/ECO（Midjourney・Canva）。DIST は巨大資本側の武器であり、スタートアップ側は Perplexity（OEM）・Glean（マーケットプレイス）・ElevenLabs（Adobe 経由）のように**買う／借りる**形で現れた。
- AI 期固有の新要素: (1) **F-PLATFORM 新型**（モデル提供者が API 顧客と競合・遮断・人材吸収）、(2) **F-ECON の再来**（推論コストで粗利 20〜40%、Cursor・Lovable・Canva・Character.ai）、(3) 巨大資本の機能投入が**撤回されうる**（Sora・Atlas）。
