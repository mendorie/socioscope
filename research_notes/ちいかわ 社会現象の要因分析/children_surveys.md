# ちいかわ：子ども（特に小学生）における認知・人気の定量調査と、ファン層の年齢・性別分布（日本、2021–2026）

調査日: 2026-10-22。各調査について「代表性のあるパネル調査」か「自己選択型（雑誌はがき・Web ポール）」かを明記した。
全体の注意: 子ども対象で**パーセンテージ付き・男女別**の完全な一次データが取れたのは ビデオリサーチ「Kids/ex」2025年10月度（2026-01-28 発表）だけ。他は順位のみ、または自己選択型。

## Q1. 子ども向け主要調査（バンダイ／学研／ニフティキッズ／小学館／ビデオリサーチ／キャラクター・データバンク）で、ちいかわは年ごとにどう出ているか

### Takeaway
最も信頼できるパネル調査（ビデオリサーチ Kids/ex、東京50km圏・3〜12歳・N=584）では、ちいかわは **2025年10月度調査で女の子1位（人気度73.9%）、子ども総合7位（52.6%）**。ただし同調査では **2024年度までちいかわは調査対象キャラに含まれておらず**（「前回調査対象外」）、2024年以前の時系列は存在しない。小学館 JS研究所（女子小学生、雑誌はがき・自己選択）では 2025年春 3位 → 2026年春 高学年1位／低学年5位。バンダイ・学研・ニフティキッズ・キャラクター・データバンクについては、2021〜2026年の「好きなキャラクター」調査でちいかわの数値を示す一次資料を**見つけられなかった**。

### Inferences

## Q2. 大人を含む全国調査でのちいかわの認知率・好感率・購入率と、年代・性別分布（20〜40代女性が中心か）

### Takeaway
全国代表サンプルの NRC（日本リサーチセンター）訪問留置調査（15〜79歳、N=1,200、2024年7月）では、ちいかわの好感率は **15〜19歳で24%と最高、20代以下で2割以上**。NRC Web 調査（15〜69歳、N=2,013、2023年12月）では「1年以内にグッズを購入したキャラクター」で**ちいかわが全体1位（5.5%、前年6位 3.3%）**、男性1位、20代・40代で1位（女性1位・10代1位・30代1位は別キャラ）。「20〜40代女性が中心」「男女比7:3」という言説は個人ブログ由来で一次調査の裏付けが見つからなかった。

- NRC 訪問調査（好感率）と NRC Web 調査（購入率）を合わせると、ちいかわの大人側の中心は **10代後半〜20代（好感）と 20代・40代（購入）**。「40代で購入1位」は親世代が子どものために購入している可能性と、40代自身のファン化の両方を含み、切り分けられない。
- 「男性で購入1位」(2023年12月) は、ちいかわ人気が女性限定ではないことの数少ない代表性ある証拠。ただし購入率 5.5% という低い絶対値のなかでの首位。
- 「20〜40代女性が中心」という通説は All About 型の自己選択調査の回答者分布（30代最多）に引きずられている可能性が高い。代表サンプルで年代×性別の好感率を見ると、むしろ 15〜19歳が最高。

## Q3. 学校での遍在の証拠（ランドセル・文房具・上履き・教材コラボ・入学準備ランキング）

### Takeaway

## Q4. 男子にも人気か（クロスジェンダーのデータ）

### Takeaway
子ども（3〜12歳）の代表性ある調査では、ちいかわは **女子1位（73.9%）だが男子 TOP10 圏外**（10位の水準は47.7%）で、男女差が大きい。一方、大人（15〜69歳）の NRC Web 調査ではちいかわが**男性のグッズ購入率1位**（2023年12月）であり、大人の男性には一定の浸透がある。小学生男子に限定した定量データは見つからなかった。
